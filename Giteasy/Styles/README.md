# Styles

## 📁 役割と責務

アプリケーション全体で共有される XAML スタイル（リソースディクショナリ）を配置するディレクトリです。
WinUI 3 の Fluent Design ガイドラインに沿った UI の一貫性を提供します。

## 現在の構成

**現在このディレクトリにスタイルファイルはありません。** スタイル定義は主に以下の場所で行われています:

- `App.xaml` — グローバルリソース（コンバーター等）
- 各ページの XAML ファイル — インラインスタイル

## 設計方針

- テーマ切替は `App.ApplyTheme()` で `ElementTheme` と `SystemBackdrop` を変更して実現
- 色やフォントの定義は WinUI 3 のシステムリソースに準拠

## ⚠️ 技術的負債

- 一部のページに色や余白のハードコード値が存在する可能性あり（テーマ切替時の追従不良の原因になりうる）
- 共有スタイルのリソースディクショナリファイルが未作成

## 🔧 拡張ガイド

- **共有スタイルの作成**: `Styles/XxxStyles.xaml` として新しいリソースディクショナリを作成 → `App.xaml` の `MergedDictionaries` に追加
- **命名規則**: ファイル名は `XxxStyles.xaml`（例: `ButtonStyles.xaml`, `ColorPalette.xaml`）
