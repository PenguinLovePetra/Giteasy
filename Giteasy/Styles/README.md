# Styles

## 📁 役割と機能 (Role & Functions)

アプリケーション全体で共有される XAML のスタイル（リソースディクショナリ）を配置するディレクトリです。

- **UI の一貫性**:
  ボタン、テキストブロック、カラーパレットなどの定義を一元管理し、WinUI 3 (Windows App SDK) の標準デザインガイドライン（Fluent Design）に沿った外観を提供します。

## ⚠️ 技術的負債と既知の課題 (Technical Debt & Known Issues)

- **ファイル分割の欠如**:
  規模が大きくなると、すべてのスタイルが一つの（または少数の） `App.xaml` やリソースディクショナリファイルに集中し、保守性が低下する恐れがあります。将来的にコントロール（Button, TextBlock 等）ごとにファイルを分割する `MergedDictionaries` の活用が必要です。
- **マジックカラー・静的定義**:
  一部にハードコードされたカラーやマージン値が存在する可能があり、テーマ（Light/Dark）の切り替え時に追従できないレイアウトのバグの温床になります。
