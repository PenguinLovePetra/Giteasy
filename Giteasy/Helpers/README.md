# Helpers

## 📁 役割と責務

ViewModel や View から使用されるユーティリティクラスを格納するディレクトリです。
横断的な関心事（ダイアログ表示など）を集約し、コードの重複を排除します。

## ファイル構成

| ファイル          | 説明                                                                   |
| ----------------- | ---------------------------------------------------------------------- |
| `DialogHelper.cs` | `ContentDialog` を使った各種ダイアログ表示ユーティリティ（静的クラス） |

### DialogHelper のメソッド一覧

| メソッド                    | 説明                                                               |
| --------------------------- | ------------------------------------------------------------------ |
| `ShowErrorAsync`            | 単純なエラーダイアログ                                             |
| `ShowErrorWithDetailsAsync` | 概要 + 折り畳み詳細付きエラーダイアログ                            |
| `ShowExceptionAsync`        | 例外オブジェクトからの詳細エラーダイアログ（スタックトレース付き） |
| `ShowInfoAsync`             | 情報ダイアログ                                                     |
| `ShowConfirmAsync`          | 確認ダイアログ（OK/Cancel → bool）                                 |

## 設計方針

- **静的メソッド**: 全メソッドが `XamlRoot` を引数に取る静的メソッド。インスタンス不要
- **日本語 UI**: ボタンラベルやデフォルト文字列は日本語で統一

## 🔧 拡張ガイド

- **新ヘルパーの追加**: このディレクトリに新しい静的クラスを作成。名前空間は `Giteasy.Helpers`
- **ダイアログの追加**: `DialogHelper.cs` に新しい静的メソッドを追加
